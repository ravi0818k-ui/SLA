What you can do with it

  • Four layouts

    Mind map, right or left tree, and an organisation chart — switch at any time without redoing the map.

  • Collapse what you know

    Fold a branch once you can recall it from memory. What is left on screen is what still needs work.

  • Notes, links, images, icons

    Attach the full explanation to a topic and keep the map itself short enough to read at a glance.

  • Export anywhere

    PNG and PDF to print or share, SVG to stay sharp at any size, Markdown and JSON to move it to another tool.

  • Import what you already wrote

    Drop in a Markdown file or an indented list and it becomes a map — headings turn into branches.

  • Works offline

    Install it from your browser's menu and it keeps working with no connection at all.

A study method, not just a drawing tool

  1. Map the chapter from memory first. Close the book and put down what you can recall. The gaps are your revision list.
  2. Fill the gaps from the book in a different branch colour, so you can see what you had missed.
  3. Collapse a branch once you can explain it out loud. Come back to the ones still open.
  4. Export to PDF the night before and revise from the one page instead of the whole chapter.

Mapping from memory before you check the book is retrieval practice — the effort of recalling is what builds the memory, which is why it beats re-reading.
