Don't have a notes file yet?

      

        This page turns a notes markdown file into a PDF — it doesn't read
        chapter PDFs directly. To make that notes file, hand your chapter to any AI tool
        (ChatGPT, Claude, Gemini, Copilot…) along with the template below. Three steps, once per chapter.
      


      

        
1

        

          
Download the template

          

            template.md is the format specification — it tells the AI exactly how to
            structure the notes. The worked example is optional but gives the AI a finished file to copy the style from.
          

          

            Download template.md
            Download example notes
          

        

      


      

        
2

        

          
Give your chapter and the template to an AI

          
Open any AI chat tool and attach:

          
    
            
  • template.md (from step 1)
    • 
            
  • your chapter — a PDF, photos of the pages, or pasted text
    • 
            
  • optional: Ch3_Atmosphere_Summary.md as a worked example
    • 
          

          
Then paste this prompt:


          

            

              Prompt — copy and paste
              
            

            
Turn the attached chapter into a notes file for a PDF generator.

Attached:
1. template.md — the specification for the notes format.
2. My chapter (PDF, images or text).
3. Optional: Ch3_Atmosphere_Summary.md — a worked example of a finished notes file.

Instructions:
- Read template.md first and follow its grammar, block order and per-block limits exactly.
- Use Recipe A (chapter summary notes) unless I tell you otherwise.
- Take every fact from my chapter only. Do not add outside information, invent
  figures or dates, or pad with generic filler. If my chapter does not cover what
  a block asks for, leave that block out rather than making something up.
- In the ## SETTINGS block, set output: to <ChapterName>_Summary.pdf
- Use the highlight markup (**bold**, ==yellow==, ++green++, !!pink!!) only on the
  key terms and definitions a student must recall — never on whole paragraphs.
- Write in plain text. No HTML and no code fences inside the notes themselves.
- Keep the language simple and direct, suitable for a school student revising.

Return the finished notes as one single .md file I can download, and nothing
else — no explanation before or after it.

          

          
Scroll inside the box to read it all — Copy takes the whole prompt.

        

      


      

        
3

        

          
Save the reply as .md and drop it above

          

            Save what the AI gives you as a file ending in .md (for example
            Ch4_MyChapter_Summary.md), then drop it into the box at the top of
            this page. Your PDF renders here in your browser, and the file never leaves your device.
          

        

      

    

  


  

    

      The notes file format is documented in
      template.md.
